# Journal

Ejercicio de Python sobre manejo de archivos de texto.



La aplicación al ejecutarse, abre un archivo de texto en donde el usuario puede registrar lo que piensa como si fuera un diario de vida, registrando automáticamente la fecha de cada entrada.



Funcionalidades actuales:



* El programa obtiene la fecha actual gracias a las herramientas de datetime.datetime. Obtiene la fecha en el momento de la ejecución con today() y le da un formato personalizado con strftime().
* Previene que se escriba más de una entrada por día y muestra cuánto tiempo falta para que se pueda escribir una nueva.
